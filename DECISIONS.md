- 2026-11-08 Flutter image pinned to `ghcr.io/cirruslabs/flutter:3.41.9` (newest tag listed on ghcr.io at start). Reason: Plan 0.2 requires exact pin.
- 2026-11-08 `curlimages/curl:8.10.1` used as a throwaway container for network lookups (host has no curl dependency).
- 2026-11-08 Removed `cupertino_icons` (unused, fewer deps). Manifest orientation set to `any` (tablets, landscape).
- 2026-11-08 `--no-web-resources-cdn` exists in Flutter 3.41.9 and is used in scripts/build_web.sh. Built output still contains gstatic/googleapis strings (flutter.js, flutter_bootstrap.js, main.dart.js); must verify at runtime in Phase 1 whether they are fetched.
- 2026-11-08 Pins: nginx:1.27.3-alpine, python:3.12.8-slim-bookworm, pytest 8.3.4, playwright image v1.49.1-noble.
- 2026-11-08 [1.1] maplibre_gl: latest is 0.28.0 (2026-11-03) but needs Flutter 3.44 / Dart 3.12 (our pinned image is 3.41.9, newest cirruslabs tag). Pinned **0.27.1** (needs Flutter >=3.29). It uses MapLibre GL JS 6.4.1 (ESM, WebGL2 only). Since 0.27 the plugin loads the JS itself (default unpkg CDN); `MapLibreJsSource.urls` points it at a self-hosted copy. Safari 15+/WebGL2 required, fine for 2021+ tablets. Upgrade path: bump Flutter image to 3.44+ and maplibre_gl 0.28.0.
- 2026-11-08 [1.2] Bundled `web/maplibre/` = maplibre-gl 6.4.1 `maplibre-gl.mjs`, `-shared.mjs`, `-worker.mjs`, `.css`, `LICENSE.txt` (BSD-3), downloaded from the npm tarball in a throwaway curl container. Set via `MapLibreMap.webLibrarySource` in main.dart using `Uri.base.resolve` (base-href safe). No external URLs inside the bundled files except comments/namespace strings.
- 2026-11-08 [1.4] Flutter 3.41.9 still emits `flutter_service_worker.js`, but it is a self-unregistering stub (deprecated). Chose a custom worker: `web/hb_sw.template.js`, filled by `scripts/gen_sw.sh` (file list + content hash cache name `hb-<hash>`), cache-first, old `hb-` caches deleted on activate, skipWaiting + clients.claim. `web/flutter_bootstrap.js` is a custom template with no serviceWorkerSettings, and registers `hb_sw.js`. Not precached: *.symbols, *.map, NOTICES, skwasm*/wimp* (only used by --wasm builds). First load downloads precache files twice (page + worker install); accepted.
- 2026-11-08 [1.5] Audit caught a real leak: default Text pulled `https://fonts.gstatic.com/s/roboto/...`. Fixed by bundling Roboto 400/500/700 (SIL OFL, from @expo-google-fonts/roboto 0.4.3) and setting `fontFamily: 'Roboto'`. Rule for the UI: only use glyphs present in Roboto, otherwise the engine will try the gstatic fallback.
- 2026-11-08 [1.5] e2e runs with `network_mode: service:serve` so the app is `http://localhost` (service workers need a secure context). nginx serves .mjs as text/javascript (GitHub Pages does too).
- 2026-11-08 [1.6] scripts/check_no_external.py allows three documented strings (CanvasKit CDN default in flutter.js/flutter_bootstrap.js, fonts.gstatic.com fallback URL and unpkg default in main.dart.js); runtime audit proves none are requested. Runs from scripts/e2e.sh before Playwright.
- 2026-11-08 [1.7] Perf probe (headless Chromium, SwiftShader software GL, 14,962-segment synthetic grid, 4 rounds of pan+wheel zoom): frames=346 median=83.3 ms p95=199.9 ms. Software rendering is far slower than a tablet GPU; indicative only.
